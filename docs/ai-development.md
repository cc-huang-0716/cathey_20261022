# AI 輔助開發方式與觀察

## 工具與使用範圍

本次使用 Codex 協助把原先的天氣查詢架構轉換成金融行情查詢系統，保留 Python FastAPI、原生前端、Docker、Google Cloud Run、GitHub Actions 與 Terraform 的技術方向。

| 階段 | AI 協助內容 | 實際驗證 |
|---|---|---|
| 規格轉換 | 將城市搜尋改為公司／代號搜尋，將預報改為歷史日行情 | 對照公開 API 實際回應可用欄位 |
| 後端 | HTTPX、資料模型、日期及金額轉換、錯誤處理 | pytest 模擬正常、缺值及來源失敗 |
| 前端 | 搜尋、行情卡片、SVG 圖表、localStorage 關注 | 靜態及功能檢查，視覺驗證範圍見 verification.md |
| 部署 | Docker、Cloud Run Terraform、GitHub Actions WIF | 真實容器執行、Terraform 格式與結構驗證 |
| 文件 | 系統架構、CI/CD 與 Git 流程圖、操作說明 | 對照實際檔案與驗證紀錄 |

## 本次開發的觀察

AI 能快速產生跨層級的初稿，但公開金融 API 的可用性與欄位不能只憑印象推測。本次先實際呼叫證交所端點，確認日期、數值、月度歷史格式後才定稿。

金融資料容易出現看似合理但語意錯誤的結果，例如把最新交易日稱為「今天」、將缺失價格轉成零、把成交股數當成張數，或用未還原股價當成投資總報酬。這些都必須在模型、畫面文字及測試中明確處理。

部署設定也需要實際驗證。Terraform validate 只能確認結構與 provider schema，不能證明 IAM、Billing、配額或網際網路來源在正式環境可用。公開雲端網址與 GitHub workflow run 必須在完成真實部署後才作為繳交證據。

這份紀錄描述工具使用及可觀察的開發結果；作者可再補上自己實際操作與面試準備的個人心得。
